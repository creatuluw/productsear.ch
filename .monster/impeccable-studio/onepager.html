Conventions strip — the archetype defaults

Type

Humanist sans for content, mono for data, counts, labels. Corpus tools lean mono-heavy; our system pairs Hanken Grotesk + Martian Mono.

Color

One accent + neutrals on a quiet ground. Ours stays the OKLCH instrument system (ink on paper, signal green, amber accent).

Space

Compact headers; row rhythm dense but regular; group gaps ≥ 2× in-group gaps; full-width rows.

Motion

Minimal: 150–300ms micro-interactions, list rows entering together, reduced-motion respected, nothing decorative.

Where we deviate — the distinctive 20%

  • PROPOSED — humans | llms dual-view on every surface: each page has a paste-ready markdown twin at ?view=llm plus /skill.md for agents — no exemplar ships this; it serves the collab-with-LLM workflow decision.
  • PROPOSED — Relevance cutoff instead of full pages: results stop when matches stop being good (rerank-score threshold), count says so — serves the "honest instrument" decision.
  • PROPOSED — Compendium by modern archetype roll-up: 20–30 workforce/business/tool-type archetypes as multi-entry jsonb (app-owned), replacing the unusable 1,320 raw categories — serves the compendium decision.
  • PROPOSED — No facet rail (pattern #7): archetype groups + search cover drill-down at this corpus size — scope decision.
