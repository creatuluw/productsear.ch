# Impeccable pattern one-pager (P3)

The **pattern one-pager** is the P3 gate deliverable of the impeccable design-studio redesign: a single self-contained HTML page showing the "80% base" layout for the redesigned productsear.ch, opened in the browser for user markup before the DESIGN-BRIEF is written.

## What it documents

- The layout skeleton — one shell, three surfaces:
  1. shell bar — nav + `humans | llms` tabs
  2. search-first header (the search field)
  3. vital-signs strip
  4. results region — relevance cutoff + pager (20/page)
  5. `/archive` — all entries, newest first
  6. `/compendium` — archetype groups with who/what/how/when cards
  7. footer — live corpus counts + `/skill.md` link
- Ten archetype-pattern verdicts: search-first header, vital-signs strip, chronological archive, compact text rows, taxonomy compendium, who/what/how/when cards, 20/page pagination, relevance honesty, calm low-chrome — **adopt**; facet rail — **deviate** (corpus too small to need one).
- The four proposed deviations (the "20%"): dual-view twins + `/skill.md` per surface; relevance cutoff (results stop when matches stop being good); compendium as 20–30 modern archetypes (multi-entry JSONB) instead of 1,320 raw categories; no facet rail.

## Details

- **Format**: self-contained HTML preview, generated by the impeccable studio P3 step (studio state in `state.json`, archetype research in `research/`)
- **Location**: `.monster/impeccable-studio/onepager.html`
- **Status**: presented at the P3 gate — verdicts are proposals pending user approval/correction; the DESIGN-BRIEF (15-principle Gestalt handover) follows approval
