# Design Context — productsear.ch

## Users
The primary user is the operator themselves: a power user / builder who maintains a large personal bookmark corpus (~2,500+ links across Raindrop) and wants to **find the right link fast** and **ask grounded questions** of it. Context of use: quick, frequent, focused lookups — often mid-task — where seconds matter. The interface is a working tool, not a marketing surface.

## Job to be done
1. Search the corpus in natural language and instantly get the most relevant bookmarks.
2. "Ask" a question and get a grounded, cited RAG answer over the top results.
3. Trust that every result is real, indexed, and traceable (no hallucinated or missing links).

## Brand Personality
**Trustworthy · Proficient · Fast.** Calm and confident, never flashy. It should feel like a precision instrument — something you trust because it is legible, consistent, and fast, not because it performs. Emotion goals: confidence, clarity, momentum.

## Aesthetic Direction
**"Instrument-grade precision tool."** A refined light theme (max legibility for fast daytime lookups): near-white cool-neutral surfaces, deep ink text, a single deep accent for structure, hairline rules, and mono numerals for data. Distinctively *not* the generic AI dark/cyan or purple-gradient look, and a deliberate move away from the current warm-paper + chrome-gradient decorative direction.

- **Theme:** Light (instrument-grade). Dark considered as a future mode, not the default.
- **Accent:** Deep ink-green (trust + "go/proficient") + warm gold used *only* as a rare speed/active signal.
- **Type:** Hanken Grotesk (sans, display + body) paired with Martian Mono for all numerals/IDs/timing — the "instrument readout" voice.
- **Anti-references:** generic AI dark dashboards, cyan-on-black, purple→blue gradients, glassmorphism, decorative chrome borders, sparkline decoration, card-soup layouts.

## Design Principles (derived from the values)
1. **Trust = legibility & consistency.** Clear hierarchy, calm palette, generous space. No decorative-for-its-own-sake elements. Every interactive state is unambiguous.
2. **Proficiency = precision & data-forwardness.** Hairline rules, a strict baseline grid, and mono-set data (counts, timing, IDs) communicate competence. Density without clutter.
3. **Speed = focus & momentum.** The search field is the hero; everything else recedes. Snappy, instant-feeling motion (ease-out-quart, 120–180ms, never bounce). The rare gold accent marks "active/running."
4. **Transparency over ornament.** Prefer showing real state (corpus size, last-indexed, query latency) over decorative effects. The status readout is the signature element.
5. **Restraint.** One accent family, one signal color used sparingly, solid colors (never gradient text), hairlines over heavy borders.

## Tokens (target — OKLCH)
- canvas `oklch(0.985 0.004 165)`, surface `oklch(0.995 0.003 165)`
- ink `oklch(0.22 0.012 165)`, ink-soft `oklch(0.48 0.012 165)`, ink-faint `oklch(0.72 0.01 165)`
- accent (ink-green) `oklch(0.42 0.09 165)` / hover `oklch(0.36 0.10 165)`
- signal (gold, active-only) `oklch(0.72 0.13 70)`
- success (teal) `oklch(0.55 0.11 165)`, border hairline `oklch(0.22 0.012 165 / 0.10)`
- radius `0.375rem`; spacing 4/8/12/16/24/32/48/64/96

## Signature element
The **instrument readout**: a slim mono status line (corpus size · last-indexed · query latency) rendered in Martian Mono, reinforcing trust (live, transparent state), proficiency (data-forward), and speed (timing shown). Replaces the current chrome-gradient gimmick.
